# Security

Please report a vulnerability privately, through GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/getgithard/githard/security), not in a public issue.

GitHard is a set of instructions for Claude Code, so the most likely problems are a skill that tells the agent to do something unsafe (expose a secret, run untrusted code, push where it shouldn't) or a script that does. Those count as vulnerabilities, and we want to hear about them.

You'll get a reply within a week. We'll agree a disclosure date with you, and credit you when the fix ships unless you'd rather not be named.

Only the latest release gets fixes.
