# Roadmap

This is the plan for the next twelve months, as of November 2026. Plans change. The [milestones](https://github.com/getgithard/githard/milestones) and the [project board](https://github.com/orgs/getgithard/projects/1) are the live version.

## By the end of 2026
- **First release, githard--v0.1.0** ([#17](https://github.com/getgithard/githard/issues/17)): installable from its own marketplace, with every skill passing its evals.
- **A README with a real before and after** ([#16](https://github.com/getgithard/githard/issues/16)), using keyparity, the project GitHard set up from an empty org.
- **Launch** ([#18](https://github.com/getgithard/githard/issues/18)).

## In 2027
- **OpenSSF silver, then gold** for GitHard itself ([#59](https://github.com/getgithard/githard/issues/59)). Gold needs a second maintainer and outside contributors, which can't be rushed.
- **More dogfood projects**, each set up from zero with GitHard alone, with every gap it hits logged and fixed.
- **Skills that grow from what people ask for** in [Discussions](https://github.com/getgithard/githard/discussions) and the skill-idea issue form.

## Not planned
- **Hosting anything for you.** GitHard runs in your Claude Code session, against your own accounts.
- **Rules about AI attribution.** GitHard follows each project's own AI policy.
