# AI policy

You're welcome to use AI tools when you contribute to {{PROJECT}}. We ask three things.

- **Say so.** If an AI tool wrote a meaningful part of your change, mention it in the PR description. One line is enough: "Drafted with an AI assistant, then reviewed and tested by me."
- **Own it.** You're responsible for every line you submit, whoever or whatever typed it. Read it, test it, and be ready to explain it in review.
- **Keep it small.** A large AI-written PR is hard to review. Split it, or open an issue first so we can agree on the shape.

PRs that look generated and unreviewed, such as code that doesn't run or descriptions that don't match the change, get closed with a note saying why.
